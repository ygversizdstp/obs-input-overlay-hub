## Overview

OBS Input Overlay Hub is a configuration companion for the OBS Input Overlay plugin, providing a visual layout editor for keyboard and controller display themes, key highlighting color configuration, mouse cursor trail settings, and profile management for switching between different input overlay setups across different game streams.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OBS Input Overlay Hub** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Layout Editor** | Visual editor for positioning input display elements on stream |
| **Color Themes** | Configure key highlight colors and animation styles per profile |
| **Controller Skins** | Custom controller button map skins for gamepad display |
| **Profile Switching** | Save and switch named overlay profiles per game or layout |
